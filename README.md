# Portafolio personal 2

Portfolio personal desarrollado con Astro, React y Tailwind para mostrar mi perfil profesional, proyectos, habilidades y contacto.

## Stack principal

- Astro
- React
- TypeScript
- Tailwind CSS
- Vercel

## Características

- Diseño moderno y responsive
- Sección de proyectos
- Información profesional y experiencia
- Botón de contacto
- Descarga de CV
- Chat assistant con IA
- Soporte en español e inglés

## Inicio rápido

```bash
pnpm install
pnpm dev
```

La app corre en:

```bash
http://localhost:4321
```

## Scripts

```bash
pnpm dev
pnpm build
pnpm preview
pnpm astro check
```

## Variables de entorno

Crear un archivo `.env` con tus claves:

```env
GROQ_API_KEY=tu_clave
RESEND_API_KEY=tu_clave
```
